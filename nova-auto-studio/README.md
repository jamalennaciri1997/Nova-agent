# NOVA Auto Studio

Android prototype: selects images, 9:16 / 16:9 / 1:1, and attempts local H.264 MP4 slideshow export with zoom. Build via `.github/workflows/build-studio.yml`.

**Not yet implemented:** video clips, audio mixing, beat detection, AI editing, editable multitrack timeline, public-gallery export.

**Warning:** Android encoder support varies; test on device. APK build and runtime success have not yet been independently verified.
